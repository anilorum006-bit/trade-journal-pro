TRADE JOURNAL PRO — iPHONE KURULUM

1. ZIP dosyasını aç. İçindeki tüm dosyaları aynı klasörde tut.
2. GitHub üzerinde yeni PUBLIC repository oluştur ve bu dosyaları kök dizine yükle.
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. GitHub Pages adresini iPhone Safari ile aç.
5. Safari Paylaş > Ana Ekrana Ekle > Ekle.
6. Uygulama içinden başlangıç kasasını gir, işlem kaydet.
7. Düzenli olarak JSON yedeği indirip iCloud Drive içine kaydet.

ÖNEMLİ: Veri cihazın uygulama depolamasında (localStorage) tutulur. GitHub verileri depolamaz. Bu sürümde bulut senkronizasyonu ve hesap girişi yoktur. Silinmeye karşı yedek gerekir.

Para yatırma/çekme kasa bakiyesini etkiler, P/L toplamına katılmaz. Haftalık dönem Pazartesi başlar. Getiri yüzdeleri basitleştirilmiş olup ara dönem yatırma/çekme olduğunda gerçek yatırım performansı (TWR) değildir.
